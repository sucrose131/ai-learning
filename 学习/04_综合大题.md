## 综合题 1：流程控制 + 运算符 —— 成绩等级判断

**题目**：输入一个 0~100 的成绩 score，编写程序按以下规则输出等级：90 及以上为"A"，80~89 为"B"，70~79 为"C"，60~69 为"D"，60 以下为"E"。要求：使用 input()、int()、if...elif...else 和比较/逻辑运算符。

【知识点】第2章 input/int 类型转换 · 第3章 比较运算符 · 第4章 if...elif...else

**参考答案**：
```python
score = int(input("请输入成绩："))

    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"

```

## 综合题 2：循环 + 列表 + 列表推导式 —— 数据统计

**题目**：使用 for 循环生成 1~20 的列表；再分别用两种方法（循环求和 与 sum()）求出所有偶数之和；最后用列表推导式生成"1~20 中所有能被 3 整除的数的平方"列表。

【知识点】第4章 for/range · 第5章 列表创建/遍历 · 第5章 sum · 第5章 列表推导式

**参考答案**：
```python
nums = list(range(1, 21))              # [1..20]

# 方法一：循环求和
s = 0
for n in nums:
    if n % 2 == 0:
        s += n
print(s)                                # 110

# 方法二：sum()
print(sum(n for n in nums if n % 2 == 0))   # 110

# 列表推导式
result = [n ** 2 for n in nums if n % 3 == 0]
print(result)   # [9, 36, 81, 144, 225, 324]
```

**题目**：给定一段字符串 text，编写程序统计其中每个字符（忽略空格）出现的次数，用字典保存，并按"键:值"逐行输出。要求使用字符串遍历、字典的键唯一性。

```python

    d[ch] = d.get(ch, 0) + 1      # 键不存在时默认0
```

## 综合题 4：函数 + 默认参数 + lambda —— 计算器函数

**题目**：编写一个函数 calc(a, b, op="+")，根据 op（+、-、*、/）返回 a 与 b 的运算结果；若 op 非法则返回 None。再写一个 lambda 表达式实现两个数相乘，并用它验证 calc 的结果。

【知识点】第9章 函数创建/调用 · 第9章 默认值参数 · 第9章 return · 第9章 lambda · 第3章 算术运算符

**参考答案**：
```python
def calc(a, b, op="+"):
    if op == "+":
        return a + b
    elif op == "-":
        return a - b
    elif op == "*":
        return a * b
    elif op == "/":
        return a / b
    return None

mul = lambda x, y: x * y
print(calc(3, 5, "*"))     # 15
print(mul(3, 5))           # 15
```

## 综合题 6：面向对象 —— 学生类与继承

**题目**：定义类 Student，含属性 name、score 和实例方法 show()；再定义子类 StudentPlus(Student)，重写 show() 方法并增加等级判断。创建实例并调用。

【知识点】第10章 class 定义 · 第10章 self/实例方法 · 第10章 继承 · 第10章 方法重写 · 第4章 if...else

**参考答案**：
```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
    def show(self):
        print(self.name, self.score)

class StudentPlus(Student):
    def show(self):            # 方法重写
        if self.score >= 60:
            level = "及格"
        else:
            level = "不及格"
        print(self.name, self.score, level)

sp = StudentPlus("Tom", 85)
sp.show()                      # Tom 85 及格
```

## 综合题 7：正则表达式 + 字符串 —— 提取邮箱

**题目**：写一个正则表达式，从字符串中匹配出形如 name@example.com 的邮箱地址，说明其中用到的元字符和限定符的含义。

【知识点】第8章 元字符 \w/. · 第8章 限定符 + · 第7章 字符串

**参考答案**：
```python
import re
text = "联系我：abc@163.com 或 test@qq.com"
pattern = r"\w+@\w+\.\w+"
print(re.findall(pattern, text))   # ['abc@163.com', 'test@qq.com']
```
说明：\w 匹配字母数字下划线或汉字；+ 匹配前面字符一次或多次；\. 匹配字面意义的点号。

## 综合题 10：数据库操作 —— SQLite 完整增删改查

## 综合题 11：面向对象 + 继承 + @property —— 矩形类

**题目**：定义 Rectangle 类，构造时传入长宽；用 @property 定义 area 属性返回面积；再定义 Square(Rectangle) 子类（正方形），重写逻辑使面积计算正确。

【知识点】第10章 class · 第10章 self · 第10章 @property · 第10章 继承 · 第3章 乘法

**参考答案**：
```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
    @property
    def area(self):
        return self.width * self.height

class Square(Rectangle):
    def __init__(self, side):
        super().__init__(side, side)   # 正方形长宽相等

print(Rectangle(3, 4).area)   # 12
print(Square(5).area)         # 25
```

**题目**：写一个交互程序，循环让用户输入两个数并做除法；用 try...except 捕获 ValueError（输入非数字）和 ZeroDivisionError（除数为0）；输入"exit"时用 break 退出循环。综合运用类型转换、while、异常处理。

```python
while True:
    s = input("输入两个数(空格分隔)，exit 退出：")
    if s == "exit":
```

## 综合题 14：字典 + 集合 + 列表推导式 —— 去重统计

**题目**：给列表 lst = [1, 2, 2, 3, 3, 3, 4]，用三种方式得到其不重复元素：(1) 用 set()；(2) 用字典的键；(3) 用列表推导式 + 判断。

【知识点】第6章 集合 · 第6章 字典 · 第5章 列表推导式

```python
lst = [1, 2, 2, 3, 3, 3, 4]
print(list(set(lst)))                          # {1,2,3,4} → [1,2,3,4]

print([x for i, x in enumerate(lst) if x not in lst[:i]])
```

## 综合题 15：模块 + 进程线程 —— 并发任务辨析

**题目**：简述进程和线程的区别；写出用 threading.Thread 和 multiprocessing.Process 各启动一个函数的代码骨架，并说明 target、args 参数含义。

【知识点】第18章 进程与线程 · 第18章 Process/Thread · 第11章 模块导入

**参考答案**：
- 进程是资源分配的基本单位，进程间内存隔离；线程是 CPU 调度的基本单位，同一进程内线程共享内存。
```python
import threading, multiprocessing

def work(name):
    print(name)

t = threading.Thread(target=work, args=("线程",))   # target=要执行的函数, args=参数元组
t.start()

p = multiprocessing.Process(target=work, args=("进程",))
p.start()
```

## 综合题 16：异常 + 文件 + 字典 + 字符串 —— 读取配置并解析

**题目**：编写程序读取一个每行形如"key=value"的配置文件，用 split() 拆分，存入字典；文件不存在时用异常处理给出提示。综合文件、字符串、字典、异常四大知识点。

【知识点】第13章 open/read · 第7章 split · 第6章 字典 · 第12章 异常处理

**参考答案**：
```python
config = {}
try:
    f = open("config.ini", "r")
except FileNotFoundError:
    print("配置文件不存在")
else:
    for line in f:
        line = line.strip()
        if "=" in line:
            k, v = line.split("=", 1)
            config[k.strip()] = v.strip()
    f.close()
print(config)
```
