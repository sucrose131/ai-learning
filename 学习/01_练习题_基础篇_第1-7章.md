【知识点】第4章·if语句
【答案】B。

**27.（判断）else 语句可以脱离 if 单独使用。（ ）**
【知识点】第4章·if...else语句
【答案】错。else 必须和 if 一起使用，不能单独出现。

**28.（代码）写出 if...elif...else 的完整结构，并说明它的执行顺序。**
【知识点】第4章·if...elif...else语句
【答案】
```python
if 表达式1:
    语句块1
elif 表达式2:
    语句块2
elif 表达式3:
    语句块3
else:
    语句块n
```
从上到下依次判断，哪个表达式为真就执行对应语句块并结束；只有所有表达式都为假时才执行 else 中的语句。

**29.（代码）用 if 嵌套实现：若 x>0 且为偶数输出"正偶数"，为奇数输出"正奇数"，否则输出"非正数"。**
【知识点】第4章·if语句的嵌套
【答案】
```python
if x > 0:
    if x % 2 == 0:
        print("正偶数")
    else:
        print("正奇数")
else:
    print("非正数")
```

**34.（代码）for 循环中 break 和 continue 有什么区别？各写一段示意代码。**
【知识点】第4章·break与continue
【答案】
```python
for i in range(5):
    if i == 3:
        break      # i 到 3 时整个循环立即结束
    print(i)       # 输出 0 1 2

for i in range(5):
    if i == 3:
        continue   # i 为 3 时跳过本次，继续下一次
    print(i)       # 输出 0 1 2 4
```

```python
while 条件表达式1:
    执行代码
    if 条件表达式2:
        break
```
条件表达式2 用于判断何时调用 break 跳出循环，避免死循环。
