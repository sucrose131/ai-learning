## 第8章 Python中使用正则表达式

**1.（单选）元字符 \d、\w、\s 分别匹配什么？（ ）**
A. 数字、字母数字下划线或汉字、空白符
B. 空白符、数字、字母
C. 字母、数字、换行
D. 数字、空白、任意字符
【知识点】第8章·常用元字符
【答案】A。

**2.（填空）"."匹配____（除换行符以外的任意字符）；^ 匹配____；$ 匹配____；\b 匹配____。**
【知识点】第8章·常用元字符
【答案】除换行符以外的任意字符；字符串的开始；字符串的结束；单词的开始或结束。

**3.（单选）限定符 ?、+、* 的含义分别是？（ ）**
A. 零次或一次、一次或多次、零次或多次
B. 一次或多次、零次或多次、零次或一次
C. 零次或多次、一次、零次或一次
D. 一次、多次、零次
【知识点】第8章·常用限定符
【答案】A。

**4.（代码）解释 colou?r 能匹配什么；go{2}gle 能匹配什么。**
【知识点】第8章·限定符·?与{n}
【答案】colou?r：? 使 u 出现零次或一次，可匹配 colour 和 color；go{2}gle：o 恰好出现2次，只匹配 google。

**5.（填空）{n,} 表示____；{n,m} 表示____。**
【知识点】第8章·限定符
【答案】匹配前面的字符最少 n 次；匹配前面的字符最少 n 次、最多 m 次。

**6.（单选）标志 I（IGNORECASE）的作用是？（ ）**
A. 不区分大小写匹配　B. 多行匹配　C. 让 . 匹配换行符　D. ASCII 匹配
【知识点】第8章·常用标志
【答案】A。

**7.（填空）S（DOTALL）标志的作用是____；M（MULTILINE）的作用是____。**
【知识点】第8章·常用标志
【答案】让 . 匹配所有字符包括换行符；让 ^ 和 $ 作用于每一行的开始和结尾。

## 第9章 函数

**8.（单选）创建函数使用哪个关键字？（ ）**
A. function　B. def　C. func　D. define
【知识点】第9章·创建函数
【答案】B。

**9.（代码）写出 def 定义函数的基本语法，并说明各部分作用。**
【知识点】第9章·创建函数
【答案】
```python
def functionname([parameterlist]):
    """comments"""      # 函数注释（文档字符串）
    functionbody        # 函数体
```
functionname 函数名；parameterlist 参数列表（多个用逗号分隔，可省略）；comments 说明函数功能；functionbody 函数体，可用 return 返回值。

**10.（判断）调用函数时，函数名必须是已经定义（创建）好的。（ ）**
【知识点】第9章·调用函数
【答案】对。

**11.（代码）定义一个带默认值参数的函数 greet(name="同学")，并说明默认值参数的好处。**
【知识点】第9章·默认值参数
【答案】
```python
def greet(name="同学"):
    print("你好，" + name)
```
好处：调用时可以省略该参数，函数使用默认值，提高灵活性。

**12.（单选）关于 return 语句，正确的是？（ ）**
A. 只能返回一个值　B. 可以返回一个值，也可以返回多个值　C. 必须有返回值　D. 只能返回字符串
【知识点】第9章·返回值
【答案】B（return 后可写 value，可返回一个或多个值；也可省略 value，表示返回 None）。

**13.（代码）匿名函数使用哪个关键字？写出一个计算两数之和的匿名函数。**
【知识点】第9章·匿名函数·lambda
【答案】lambda。
```python
add = lambda x, y: x + y
add(3, 5)   # 8
```

**14.（填空）lambda 表达式的结构是：result = lambda [参数列表] : ____。**
【知识点】第9章·匿名函数
【答案】expression（表达式，是必选参数，实现具体功能）。

## 第10章 面向对象程序设计

**15.（单选）定义类使用哪个关键字？（ ）**
A. class　B. def　C. struct　D. object
【知识点】第10章·定义类
【答案】A。

**16.（代码）写出 class 定义类的基本语法，并说明类体主要由什么组成。**
【知识点】第10章·定义类
【答案】
```python
class ClassName:
    """类的帮助信息"""   # 类文档字符串
    statement           # 类体
```
类体主要由类变量（类成员）、方法、属性等定义语句组成；没想好功能时可用 pass 占位。

**17.（判断）class 语句本身不会创建任何实例，需要用类名调用（实例化）来创建对象。（ ）**
【知识点】第10章·创建类的实例
【答案】对。

**18.（填空）实例方法的第一个参数必须是____，它表示____；其名称只是惯例。**
【知识点】第10章·实例方法·self
【答案】self；类的实例（可以换成其他名字，但惯例用 self）。

**19.（代码）写出通过实例访问方法的一般语法。**
【知识点】第10章·访问实例方法
【答案】
```python
instanceName.functionName(parametervalue)
```

**20.（填空）@property 装饰器的作用是把一个方法变成____，在方法体中通常以____语句结束。**
【知识点】第10章·@property
【答案】"用于计算的属性"（可像属性一样访问）；return（返回计算结果）。

**21.（代码）写出继承的基本语法，并说明不指定基类时的默认情况。**
【知识点】第10章·继承
【答案】
```python
class ClassName(baseclasslist):
    """类的帮助信息"""
    statement
```
baseclasslist 为要继承的基类，可有多个（逗号分隔）；不指定时默认继承所有对象的根类 object。

**22.（判断）方法重写是指在派生类中重新定义基类中已有的方法，以实现不同行为。（ ）**
【知识点】第10章·方法重写
【答案】对。

## 第12章 异常处理及程序调试

**28.（单选）访问一个没有声明的变量引发的异常是？（ ）**
A. NameError　B. IndexError　C. KeyError　D. TypeError
【知识点】第12章·常见异常
【答案】A。

**29.（填空）索引超出序列范围是____；请求不存在的字典键是____；除数为0是____；类型不合适是____。**
【知识点】第12章·常见异常
【答案】IndexError；KeyError；ZeroDivisionError；TypeError。

**30.（代码）写出 try...except 的语法，并说明 except 中 ExceptionName as alias 的作用。**
【知识点】第12章·try...except语句
【答案】
```python
try:
    block1               # 可能出现错误的代码
except [ExceptionName [as alias]]:
    block2               # 捕获异常后的处理
```
ExceptionName 指定要捕获的异常类型；as alias 给异常起别名，可用别名记录异常具体内容。

**31.（判断）finally 代码块中的代码在任何情况下都会执行。（ ）**
【知识点】第12章·try...except...finally
【答案】对。finally 用于放置任何情形都必须执行的代码（如释放资源）。

**32.（填空）抛出异常使用____语句；其语法为 raise [ExceptionName[(reason)]]，reason 用于____。**
【知识点】第12章·raise语句
【答案】raise；对异常信息做相关描述。

**33.（单选）assert 语句中，当 expression 为假时会怎样？（ ）**
A. 什么都不做　B. 抛出 AssertionError 异常　C. 输出 reason 并继续　D. 退出循环
【知识点】第12章·assert语句
【答案】B。assert expression[, reason] 中，表达式为真什么都不做，为假则抛出 AssertionError。

A. connect()　B. cursor()　C. commit()　D. execute()
【知识点】第14章·连接对象

【知识点】第14章·connect参数

**42.（单选）连接对象的方法中，commit() 和 rollback() 的作用分别是？（ ）**
A. 提交事务、回滚事务　B. 回滚事务、提交事务　C. 关闭连接、获取游标　D. 获取游标、提交事务

**44.（代码）游标对象获取查询结果的三种方式及区别。**
【知识点】第14章·游标对象方法
【答案】


**46.（代码）写出 SQLite 新增、查询、修改、删除数据的 SQL 语句模板。**
【知识点】第14章·操作SQLite
【答案】
