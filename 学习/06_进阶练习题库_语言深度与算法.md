### 1. 迭代器 / 生成器

**A1.（单选）生成器（generator）相比一次性生成整个列表的最大优势是？（ ）**
A. 更快地随机访问　B. 惰性求值、节省内存　C. 可以修改元素　D. 线程安全
【知识点】语言深度·生成器·惰性求值
【答案】B。

**A2.（填空）一个函数里只要出现了____关键字，它就不再是普通函数，而是生成器函数；调用它返回的是一个____对象。**
【知识点】语言深度·生成器·yield
【答案】yield；生成器（generator）。

**A3.（代码）手写一个生成前 n 个斐波那契数的生成器，并说明它的执行过程。**
【知识点】语言深度·生成器·yield
【答案】
```python
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

for x in fib(10):
    print(x)
```
每次执行到 yield 时"暂停"并返回值；下次调用 `next()` 从 yield 之后继续，状态被保留。

**A4.（代码）迭代器协议的两个方法是什么？写出一个可迭代的类。**
【知识点】语言深度·迭代器·`__iter__`/`__next__`
【答案】
```python
class Count:
    def __init__(self, n):
        self.n = n
        self.i = 0
    def __iter__(self):
        return self
    def __next__(self):
        if self.i >= self.n:
            raise StopIteration
        self.i += 1
        return self.i - 1
```

### 2. 装饰器 / 闭包

**A5.（填空）装饰器本质上是一个接收____作为参数、并返回____的函数；闭包是指函数内部引用了____的变量。**
【知识点】语言深度·装饰器与闭包
【答案】函数；一个新函数；外层函数（自由变量/外部作用域）。

**A6.（代码）手写一个计时装饰器，打印函数运行耗时（用 `functools.wraps` 保留原函数信息）。**
【知识点】语言深度·装饰器·wraps
【答案】
```python
import time, functools

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(func.__name__, "耗时", time.time() - start)
        return result
    return wrapper

@timer
def work():
    time.sleep(0.1)
```

**A7.（代码）写出带参数的装饰器（如 `@repeat(3)` 让函数执行 3 次）的结构。**
【知识点】语言深度·带参装饰器
【答案】
```python
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator
```

**A11.（代码）为类 Point 实现 `__eq__`，使两个点坐标相同即相等；并说明若不实现 `__eq__`，`==` 比较的是什么。**
【知识点】语言深度·魔术方法·`__eq__`
【答案】
```python
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
```

### 5. 可变性 / 深浅拷贝

**A13.（代码）解释下面代码的输出，并说明原因。**
```python
def f(a=[]):
    a.append(1)
    return a
print(f())   # ?
print(f())   # ?
```
【知识点】语言深度·可变对象·默认参数陷阱
【答案】输出 [1] 和 [1, 1]。默认参数 [] 在函数定义时只创建一次，后续调用共享同一个列表。正确写法：`def f(a=None): a = a or []`。

**A14.（代码）`is` 与 `==` 的区别是什么？写出浅拷贝与深拷贝的代码及区别。**
【知识点】语言深度·深浅拷贝
【答案】
```python
import copy
a = [[1, 2], [3, 4]]
b = copy.copy(a)        # 浅拷贝：外层新列表，内层仍共享
c = copy.deepcopy(a)    # 深拷贝：内外层全部新建
```
`is` 比较内存地址（是否同一对象），`==` 比较值是否相等。

### 8. 内存模型 / GIL / 并发

**A20.（简答）什么是 GIL？为什么它让 Python 多线程在 CPU 密集型任务上表现不佳，却对 IO 密集型任务仍有帮助？**
【知识点】语言深度·GIL
【答案】GIL（全局解释器锁）同一时刻只允许一个线程执行 Python 字节码，因此多线程无法真正并行执行 CPU 密集计算；但 IO 等待时会释放锁，其他线程可运行，所以对 IO 密集型（网络、文件）任务仍有并发收益。

**A21.（代码）用 asyncio 并发执行两个协程，并说明 async/await 的含义。**
【知识点】语言深度·asyncio
【答案】
```python
import asyncio

async def task(name):
    print(name, "开始")
    await asyncio.sleep(1)   # await 挂起，让出控制权
    print(name, "结束")

async def main():
    await asyncio.gather(task("A"), task("B"))

asyncio.run(main())
```
`async def` 定义协程函数；`await` 挂起当前协程、等待可等待对象完成。

### 2. 数组 / 链表 / 栈 / 队列

**B4.（代码）用 Python 实现一个栈（push/pop/peek/是否为空），基于 list 实现即可。**
【知识点】数据结构·栈
【答案】
```python
class Stack:
    def __init__(self):
        self.items = []
    def push(self, x):
        self.items.append(x)
    def pop(self):
        return self.items.pop()
    def peek(self):
        return self.items[-1]
    def is_empty(self):
        return len(self.items) == 0
```

**B5.（代码）用 collections.deque 实现一个队列（入队/出队），并说明为什么不用 list.pop(0)。**
【知识点】数据结构·队列
【答案】
```python
from collections import deque
q = deque()
q.append(1)      # 入队
x = q.popleft()  # 出队 O(1)
```
`list.pop(0)` 会移动后面所有元素，是 O(n)；deque 两端操作是 O(1)。

**B6.（简答）数组和链表的区别（随机访问、插入删除的时间复杂度）。**
【知识点】数据结构·数组vs链表
【答案】数组连续存储，随机访问 O(1)，但中间插入/删除需移动元素 O(n)；链表随机访问需遍历 O(n)，但插入/删除 O(1)（已知节点位置）。

**B7.（代码）用栈实现"括号匹配校验"，判断字符串中 `()[]{}` 是否配对。**
【知识点】数据结构·栈·应用
【答案】
```python
def is_valid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack
```

### 3. 哈希表 / 字典

**B8.（代码）给定数组，找出"两数之和"等于 target 的下标（用字典优化到 O(n)）。**
【知识点】数据结构·哈希表
【答案】
```python
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
```

**B12.（代码）用 BFS 求二维网格中从起点到终点的最短步数（框架代码，说明用队列）。**
【知识点】算法·BFS
【答案】
```python
from collections import deque
def bfs(grid, start, target):
    q = deque([(start[0], start[1], 0)])  # (行,列,步数)
    visited = {start}
    while q:
        r, c, step = q.popleft()
        if (r, c) == target:
            return step
        for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]) \
               and grid[nr][nc] == 0 and (nr, nc) not in visited:
                visited.add((nr, nc))
                q.append((nr, nc, step+1))
    return -1
```

### 5. 排序 / 查找 / 递归

**B13.（代码）手写快速排序或归并排序（选其一）。**
【知识点】算法·排序
【答案】（快速排序）
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left  = [x for x in arr if x < pivot]
    mid   = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
```

**B14.（代码）写一个二分查找，在有序列表中返回目标下标，不存在返回 -1。**
【知识点】算法·二分查找
【答案】
```python
def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

**B15.（代码）用递归计算 n 的阶乘，并写出递归的两个必要条件。**
【知识点】算法·递归
【答案】
```python
def factorial(n):
    if n <= 1:      # 终止条件（基线）
        return 1
    return n * factorial(n - 1)   # 递归调用，向基线逼近
```
递归两要素：基线条件（何时停止）+ 递归调用（问题规模缩小）。

### 6. 动态规划（入门）

**B16.（代码）用"记忆化递归"或"迭代 DP"求第 n 个斐波那契数，使复杂度从指数降到 O(n)。**
【知识点】算法·动态规划
【答案】
```python
def fib_dp(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b
```

**B17.（代码）爬楼梯问题：一次可爬 1 或 2 阶，爬到第 n 阶有多少种方法？（提示：dp[n] = dp[n-1] + dp[n-2]）**
【知识点】算法·动态规划·状态转移
【答案】
```python
def climb_stairs(n):
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b
```
