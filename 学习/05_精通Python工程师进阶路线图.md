# 精通 Python 工程师 · 进阶路线图

> 定位：你已经通过《Python从入门到精通·背记手册》完成了"语法广度扫盲"（21 章：语法、数据结构、函数、OOP、模块、异常、文件、数据库、GUI、爬虫、并发、网络、Web/Flask）。
> 这份路线图解决的是：从"会写 Python"到"精通 Python 工程师"之间还缺什么、按什么顺序补、用什么资源、怎么检验。

---

## 先看一张总图

```
阶段0 巩固基础 ──► 阶段1 语言深度 ──► 阶段2 工程化能力
                                        │
              ┌─────────────────────────┤
              ▼                         ▼
    阶段3 算法与计算机基础        阶段4 主方向深挖(Web后端)
              │                         │
              └──────────┬──────────────┘
                         ▼
              阶段5 实战项目 + 开源 + 持续学习
```

**核心原则**：
1. 深度优先于广度——先把一门主线做透，再横向扩展。
2. 每个知识点都要"能写出代码 + 能讲清原理"，而不是背下来。
3. 从阶段 2 开始，所有代码都用 Git 管理，并养成写测试的习惯。

---

## 阶段 0：巩固当前基础（1~2 周）

**目标**：把手册 21 章真正吃透，而不是"背过就忘"。

- 用已生成的 4 份练习题库（`01~04`）自测，错题回到对应知识点。
- 检验标准：不看答案能独立写出常用语法（切片、列表推导式、dict/set、try/except、类与继承、open 读写、import）。

---

## 阶段 1：语言深度（4~8 周）★ 最重要

**目标**：理解 Python 对象模型和高级特性，这是"精通"和"会用"的分水岭。

| 主题 | 必会点 | 检验标准 |
|------|--------|---------|
| 迭代器 / 生成器 | `__iter__`/`__next__`、`yield`、`yield from`、生成器表达式 | 手写一个惰性斐波那契生成器 |
| 装饰器 / 闭包 | 闭包原理、无参/有参/带状态装饰器、`functools.wraps` | 手写计时装饰器和带参数装饰器 |
| 上下文管理器 | `with`、`__enter__`/`__exit__`、`contextlib.contextmanager` | 手写一个"文件安全打开"上下文管理器 |
| 魔术方法 | `__getitem__` `__eq__` `__call__` `__repr__` `__hash__` 等 | 手写一个可迭代、可比较的自定义容器 |
| 可变性与拷贝 | 默认参数陷阱、浅拷贝/深拷贝、`is` vs `==` | 讲清 `a = [1,2]; b = a[:]` 与浅拷贝区别 |
| 类型系统 | 类型注解、`dataclass`、`Enum`、`typing` | 用 dataclass 重构一个普通类 |
| 标准库 | `collections`(deque/Counter/defaultdict)、`itertools`、`functools` | 用 Counter 做词频统计 |
| 内存模型 | 引用计数、`gc`、GIL、可变与不可变对象 | 解释 GIL 为什么影响多线程 CPU 密集任务 |
| 并发进阶 | `asyncio`/`async`/`await`、`ThreadPoolExecutor`/`ProcessPoolExecutor` | 用 asyncio 并发抓取 3 个 URL |

**推荐资源**：
- 《流畅的 Python》（Fluent Python，第 2 版）—— 语言深度的首选书。
- 《Python Cookbook》—— 常见问题的最佳写法。
- 官方文档 + Real Python 教程（免费）。

---

## 阶段 2：工程化能力（2~4 周，可与阶段 1 并行）

**目标**：把"脚本"变成"工程"。

| 主题 | 必会点 |
|------|--------|
| 环境与包管理 | venv / poetry / uv，`requirements.txt` / `pyproject.toml` |
| 代码规范 | PEP 8、`ruff`/`flake8` 检查、`black` 格式化 |
| 测试 | `pytest`、参数化测试、`mock`/`monkeypatch`、覆盖率 |
| 日志与调试 | `logging`（级别/格式/Handler）、`pdb`、断点 |
| 版本控制 | Git 基础、分支、`.gitignore`、GitHub PR 与 Code Review |
| 性能剖析 | `cProfile`、`timeit`，定位瓶颈 |
| 文档 | docstring 规范、Sphinx |

**检验标准**：给一个自己写的小脚本补上——虚拟环境、类型注解、pytest 测试、日志、Git 提交、README。

---

## 阶段 3：算法与计算机基础（长期，建议每天 1 小时）

**目标**：补"内功"，这是面试和解决复杂问题的硬通货。

| 主题 | 必会点 |
|------|--------|
| 数据结构 | 数组/链表/栈/队列/哈希表/堆/树/图 |
| 算法 | 排序、二分、递归、双指针、滑动窗口、BFS/DFS、动态规划入门 |
| 复杂度 | 时间/空间复杂度分析，能估算并优化 |
| 操作系统 | 进程/线程/协程、内存、文件系统、Linux 基本命令 |
| 网络原理 | TCP/IP、HTTP、DNS、三次握手/四次挥手 |
| 数据库原理 | 事务 ACID、索引(B+树)、SQL 优化 |

**推荐资源**：
- 刷题：LeetCode（从 Easy 开始，按 tag 刷）。
- 书：《算法图解》（入门）、《Hello 算法》（免费在线，中文友好）。
- 计算机基础：图解 HTTP、图解 TCP/IP，配合实际抓包理解。

---

## 阶段 4：主方向深挖 —— Web 后端（8~12 周）★ 求职主线

**目标**：做出能上线、能抗住基本流量的后端服务。这是目前 Python 需求量最大的方向。

| 主题 | 必会点 |
|------|--------|
| Web 框架 | Django（全家桶）或 FastAPI（现代、异步、自动文档），建议二选一深挖 |
| REST API | 设计规范、状态码、分页、参数校验 |
| ORM | SQLAlchemy / Django ORM、迁移（Alembic/migrations） |
| 数据库 | MySQL/PostgreSQL 的 SQL 硬功夫：联表、索引、事务、范式 |
| 缓存/队列 | Redis（缓存、分布式锁）、Celery + RabbitMQ 异步任务 |
| 鉴权 | Session/Cookie、JWT、OAuth2 基础 |
| 部署 | Docker、Nginx + Gunicorn/uWSGI、Linux 服务器、CI/CD（GitHub Actions） |

**检验标准**：完成一个带"用户注册登录 + 增删改查 + 缓存 + 异步任务 + Docker 部署"的完整 API 项目。

---

## 阶段 5：实战 + 开源 + 持续学习（贯穿始终）

- **项目闭环**：需求 → 设计 → 编码 → 测试 → 部署 → 监控，至少 2~3 个完整项目写进简历。
- **读源码**：从 `requests`、`Flask` 这类中小型库开始读，理解优秀设计。
- **开源贡献**：提 issue、修 bug、写文档，哪怕很小的 PR。
- **输出倒逼输入**：写博客/笔记，讲清楚一个知识点才算真会。
- **英语**：坚持读官方文档和英文技术博客，手册里的"英语词汇"要继续积累。

---

## 学习节奏建议

- 每天固定 1~2 小时，**编码 > 看书**，保证动手量。
- 阶段 1 和阶段 3 可长期并行：上午语言深度，晚上算法刷题。
- 每两周做一次"检验标准"自测，卡住的地方就是下两周的重点。

## 一句话总结

> 手册给了你"Python 的地图"，路线图补的是"地形、装备和实战"。真正决定你高度的，是**语言深度 + 工程习惯 + 算法内功 + 一个做透的实战方向**。
