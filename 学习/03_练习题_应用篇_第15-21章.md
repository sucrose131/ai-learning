【知识点】第18章·互斥锁
【答案】
```python
import threading
mutex = threading.Lock()     # 创建锁

# ...临界区代码...
mutex.release()              # 释放锁
```

## 第19章 网络编程

**23.（单选）IP 协议与 TCP 协议的关系是？（ ）**
A. 无关　B. TCP 建立在 IP 之上，负责可靠连接、保证数据包按顺序到达　C. IP 建立在 TCP 之上　D. 二者相同
【知识点】第19章·IP与TCP协议
【答案】B。IP 负责把数据从一台计算机发到另一台；TCP 建立在 IP 之上保证可靠连接。

**24.（填空）Socket 的中文常称为____，用于描述____和____，是一个通信链的句柄。**
【知识点】第19章·Socket简介
【答案】套接字；IP 地址；端口。

**25.（单选）Socket 服务端正确的方法调用顺序是？（ ）**
A. bind → listen → accept　B. connect → send → recv　C. accept → bind → listen　D. recv → bind → listen
【知识点】第19章·Socket内置方法
【答案】A。

**26.（填空）s.bind() 用于____；s.listen() 用于____；s.accept() 用于____。**
【知识点】第19章·Socket方法
【答案】绑定地址（host,port）到套接字；开始 TCP 监听；被动接受 TCP 客户端连接（阻塞式等待）。

**27.（代码）recv() 与 sendall() 的区别是什么？**
【知识点】第19章·Socket收发
【答案】recv() 接收 TCP 数据（数据以字符串形式返回，bufsize 指定最大接收量）；sendall() 完整发送 TCP 数据（返回前会尝试发送所有数据，成功返回 None，失败抛异常），而 send() 返回值可能小于要发送的字节数。

**28.（单选）UDP 收发数据使用哪两个方法？（ ）**
A. recvfrom / sendto　B. recv / send　C. recv / sendall　D. bind / accept
【知识点】第19章·UDP方法
【答案】A。
